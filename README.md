# 当前视频 · 声音弹幕播放页 2.0.0

此版本对应你选择的“生成播放页面，播放当前视频并带声音、弹幕”。采用原播放器移入独立窗口的方式；不是导出视频文件，也不是生成可分享、可独立运行的视频直链。

## 安装和使用

1. 在 Tampermonkey 中禁用旧的“通用视频解析助手”。
2. 新建脚本，将 CurrentVideoPlayer.user.js 全部粘贴进去并保存。
3. 刷新网页，播放要观看的视频，并开启原播放器弹幕。
4. 点击“当前视频播放页”。插件只选择当前可见且正在播放的视频；没有视频在播放或多个视频同时播放时会提示，不随机选取其他视频。
5. 声音、弹幕和控制使用原播放器。按住悬浮按钮可拖动，松开后保存位置。
6. 关闭播放页或点击“返回原网页”，播放器会尝试恢复到原位置。

## 声音与弹幕

移动的是原始播放器节点而非复制无声视频轨，因此播放器自身负责音视频同步。插件会尝试取消视频静音，并提供“开启声音”按钮；浏览器可能要求你再点击播放按钮。

已识别播放器容器：B 站、DPlayer、ArtPlayer、XGPlayer、Video.js、Plyr。此列表表示代码包含容器识别规则，不表示已完成这些网站或播放器的真实兼容性验证。原播放器容器内已有的 DOM/Canvas 弹幕一起移入，不重新读取弹幕 API，不新增或烧录弹幕。

未知播放器仅移动视频的紧邻容器。容器之外的弹幕、iframe 外的独立声音组件、全局脚本绘制的弹幕、关闭的 Shadow DOM 等无法保证保留。当前版本不会汇总跨域 iframe；在该播放器所在框架内点击按钮。

## 限制

原网页必须保持打开，并避免切换视频、清晰度或跳转网页。原播放器的脚本仍依赖原网页。DOM 跨窗口移动可能触发浏览器媒体重载、网站重新挂载播放器或使弹幕脚本找不到节点，导致画面、声音或弹幕异常；这类网站请关闭播放页返回原网页。原网页关闭后播放页无法继续可靠运行。

不支持保证任意网站兼容，不绕过登录、付费或 DRM。此版不再扫描全页视频候选、不复制无声视频轨，不生成可分享播放链接。浏览器拦截弹窗时需允许目标网站弹出窗口。

## 验证

通过 JavaScript 语法检查和模拟选择测试：排除暂停视频、只选可见正在播放的视频、多视频拒绝自动选择、识别播放器容器、不移动整个网页。尚未在真实浏览器验证媒体跨窗口移动、关闭还原及声音/弹幕效果。
